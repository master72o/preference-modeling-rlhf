# Figures Directory

This directory contains visual comparison charts generated by the Preference Reward Calibration suite:
- `reward_accuracy_comparison.png`: Bar chart comparing Pairwise Accuracy (%) and Expected Calibration Error (ECE %) across RM checkpoints (RM v1 Baseline, RM v2 DPO Calibrated, RM v3 Margin Scaled).
- `calibration_reliability_diagram.png`: Reliability Diagram plotting Predicted Sigmoid Probability $P(\text{chosen} \succ \text{rejected})$ against Actual Empirical Accuracy per confidence bin.
- `reward_margin_distribution.png`: Bar chart tracking mean reward margin $\Delta r = r_{\text{chosen}} - r_{\text{rejected}}$ progression across RM checkpoints.
